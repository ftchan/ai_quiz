# AI Quiz

漳州市人工智能工程技术职业技能竞赛理论题刷题网页。

当前题库共 305 道：理论题库 291 道（从“理论题”文件夹的 4 份表格中解析并去重导入），样题补充 14 道。题目卡会标记“样题”来源。

## 文件

- `index.html`：页面入口
- `style.css`：页面样式
- `app.js`：答题、背题和本地统计逻辑
- `questions.js`：从竞赛题样题表格整理出的本地题库（90 道单选题、40 道多选题）

## 运行

这是一个纯静态网页，可直接打开 `index.html`。也可以在此目录启动任意静态文件服务器后访问。

## 数据同步

顶部工具区可导出学习数据 JSON 文件，并在另一设备导入。数据包含答题记录、错题清单、收藏、背题进度和背题模式；导入会覆盖当前浏览器的对应学习数据。
